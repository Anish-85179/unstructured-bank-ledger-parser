# Bank Statement Parsing & Automated Reconciliation Engine

## Executive Summary
An end-to-end financial data analytics and ledger reconciliation engine developed in Excel. It parses raw bank statement CSV exports, categorizes debit and credit cash flows, isolates ledger discrepancies, and generates an automated monthly bank reconciliation summary.
